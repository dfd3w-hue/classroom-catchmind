# 교실 캐치마인드

교사 화면(방 번호·타이머·정답 제출 현황·실시간 그림·학생 목록)과 학생 태블릿 화면(제시어·그림판·정답 비밀 제출·라운드 결과)으로 이루어진 실시간 그림 퀴즈입니다.
학교 네트워크에서 외부 사이트가 막혀 있어도 **선생님 노트북에서 서버를 실행하고 같은 Wi-Fi의 태블릿으로 접속**하면 사용할 수 있습니다.

## 1. 준비 (한 번만)

1. https://nodejs.org 에서 **LTS** 버전을 설치합니다.
2. 이 폴더에서 터미널(명령 프롬프트/PowerShell)을 열고 아래를 실행합니다.

```bash
npm install
```

## 2. 실행

```bash
npm start
```

실행하면 터미널에 아래와 같이 주소가 출력됩니다.

```
교실 캐치마인드 서버 실행 중
  교사 화면 : http://localhost:3000/teacher.html
  학생 접속 : http://192.168.0.12:3000/student.html
```

- 선생님: `http://localhost:3000/teacher.html` 을 열면 방 번호(4자리)가 생성됩니다. 교사 화면 오른쪽 아래에도 학생 접속 주소가 표시됩니다.
- 학생: 태블릿 브라우저에서 `http://192.168.0.12:3000/student.html` (숫자는 선생님 노트북의 IP)로 접속 → 방 번호와 이름 입력.
  - `http://192.168.0.12:3000/student.html?code=1234` 처럼 주소 뒤에 방 번호를 붙이면 자동으로 입력됩니다.

## 3. 게임 진행

1. 학생들이 입장하면 교사 화면 오른쪽 목록에 나타납니다.
2. 학생 이름을 클릭(또는 **출제자 랜덤**)해서 출제자를 정하고, 제시어 범주와 제한 시간을 고른 뒤 **라운드 시작**을 누릅니다.
   - 제시어를 직접 입력하면 그 단어가 출제됩니다 (수업 단원 용어 등).
3. 출제자 태블릿에만 제시어가 보이고, 그림을 그리면 교사 화면과 모든 학생 화면에 실시간으로 나타납니다.
4. 나머지 학생은 정답을 입력해 **비밀로 제출**합니다. 시간 안에 다시 제출하면 수정됩니다. 교사 화면에는 "정답 제출 3 / 12명"처럼 제출 현황만 보입니다.
5. 시간이 끝나거나 **라운드 종료**를 누르면 정답이 공개되고 자동 채점됩니다.
   - 맞힌 학생 +10점, 출제자는 맞힌 학생 1명당 +5점
   - 띄어쓰기와 영문 대소문자는 무시하고 비교합니다.
6. **다음 라운드 준비**를 누르면 다음 학생이 출제자로 자동 선택됩니다(이름 순). 바꾸려면 다른 학생을 클릭하면 됩니다.

학생이 새로고침하거나 잠시 연결이 끊겨도 같은 이름으로 다시 들어오면 점수가 유지됩니다.

## 4. 문제 해결

| 증상 | 확인할 것 |
|---|---|
| 학생 태블릿에서 접속이 안 됨 | 노트북과 태블릿이 **같은 Wi-Fi**인지 확인. Windows 방화벽에서 Node.js 허용(처음 실행 시 뜨는 창에서 "허용"). 그래도 안 되면 방화벽 인바운드 규칙에 TCP 3000 포트를 추가 |
| 같은 Wi-Fi인데도 안 됨 | 학교 Wi-Fi가 기기 간 통신(AP isolation)을 막는 경우입니다. 노트북의 모바일 핫스팟을 켜고 태블릿을 그 핫스팟에 연결하면 인터넷 없이도 동작합니다 |
| 포트 3000이 이미 사용 중 | `PORT=4000 npm start` (Windows PowerShell: `$env:PORT=4000; npm start`) |
| 그릴 때 화면이 스크롤됨 | 최신 브라우저(Chrome, Safari, Edge)를 사용하세요. 캔버스에 `touch-action: none`이 적용되어 있습니다 |

## 5. 인터넷에 올려서 쓰기 (선택)

집에서도 테스트하거나 교내 차단이 "특정 사이트만 차단" 방식이라면 외부 호스팅도 가능합니다.

1. 이 폴더를 GitHub 저장소에 올립니다 (`node_modules`는 제외).
2. https://render.com 에서 **New → Web Service** → 저장소 연결.
   - Build command: `npm install`
   - Start command: `npm start`
3. 배포된 주소(예: `https://내프로젝트.onrender.com/teacher.html`)로 접속합니다. 교사 화면에 학생 접속 주소가 자동으로 표시됩니다.

무료 플랜은 15분 동안 사용이 없으면 잠들어 첫 접속이 30초 정도 느릴 수 있습니다.

## 6. 커스터마이징

- 제시어 목록: `words.json` 에서 범주와 단어를 자유롭게 추가·수정합니다. 서버를 다시 시작하면 반영됩니다.
- 점수 규칙: `server.js` 의 `endRound` 함수에서 `p.score += 10`, `correctCount * 5` 부분을 바꿉니다.
- 제한 시간 선택지: `public/teacher.html` 의 `<select id="seconds">` 옵션을 수정합니다.
- 색상·디자인: `public/style.css`

## 폴더 구성

```
classroom-catchmind/
├─ server.js          # 서버 (방·라운드·채점·그림 중계)
├─ words.json         # 제시어 목록 (범주별)
├─ package.json
└─ public/
   ├─ index.html      # 시작 페이지
   ├─ teacher.html    # 교사 화면
   ├─ teacher.js
   ├─ student.html    # 학생 태블릿 화면
   ├─ student.js
   ├─ shared.js       # 공용 캔버스 코드
   └─ style.css
```
